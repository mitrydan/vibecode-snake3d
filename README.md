# Snake 3D

3D игра «Змейка» на базе Three.js и HTML5 Canvas.

## Запуск

```bash
cd games/snake
npm install
npm run dev
```

Для сборки продакшн-версии:
```bash
npm run build
```

Для запуска тестов игровой логики:
```bash
npm test
```

## Режимы игры
- **👤 1 Игрок**: классический режим с выбором камеры (3D, Сверху, 1-е лицо).
- **👥 2 Игрока (Дуэль)**: две змейки на одной арене соревновательного матча с отдельными очками и выявлением победителя при столкновении.

## Управление
### Одиночный режим:
- **WASD** или **Стрелки**: поворот змейки
- **C**: переключение камеры (**3D** / **Сверху** / **От 1-го лица**)
- В режиме 1-го лица: **A** / **D** — поворот налево/направо относительно взгляда

### Режим на двоих (2 Игрока):
- **Игрок 1 (Зелёная змейка)**: клавиши **W**, **A**, **S**, **D**
- **Игрок 2 (Оранжевая змейка)**: стрелки клавиатуры (**▲**, **◀**, **▼**, **▶**)

### Общее:
- **Пробел**: пауза / возобновление
- **R**: рестарт игры
- **Зажатие левой кнопки мыши + движение**: вращение камеры (в 3D)
